# AETHER ATELIER — Modern E-Commerce Clothing Store

An online luxury clothing store built with contemporary editorial design, interactive shopping cart, size selections, multi-step checkout, and full responsive support for mobile and desktop.

## Live Deployment
- **Live URL**: [https://joshuahan07.github.io/tastelabsuxprobe/sites/ecommerce/antigravity/](https://joshuahan07.github.io/tastelabsuxprobe/sites/ecommerce/antigravity/)

## Key Features

1. **Curated Product Catalog**:
   - 12 contemporary designer garments (Cashmere overcoats, tailored blazers, mohair knitwear, silk midi dresses, Japanese selvedge denim, Italian leather goods).
   - High-resolution editorial photography with dual-image hover transitions.
   - Real-time rating and review counts.
   - Dynamic price calculations, discount comparison, and limited-edition badges.

2. **Interactive Size & Color Selection**:
   - Available sizes preview on cards (`XS`, `S`, `M`, `L`, `XL`, `XXL`).
   - Real-time stock availability indicators ("Only 2 left in M!").
   - Integrated Size & Measurement Guide modal with inch and centimeter tables.
   - Color swatch selectors.

3. **Category Filtering & Search**:
   - Filter by categories: *All Pieces*, *Outerwear*, *Tailoring*, *Knitwear*, *Dresses*, *Trousers*, *Tops*, and *Accessories*.
   - Filter by size chips.
   - Sort by *Featured*, *Price: Low to High*, *Price: High to Low*, *Highest Rated*, and *Newest*.
   - Live instantaneous search across product names, descriptions, and categories.

4. **Slide-Out Shopping Bag**:
   - Interactive cart drawer with itemized listing.
   - Real-time free shipping threshold tracker ($150 target with dynamic progress bar).
   - Stepper for adjusting quantities or removing items.
   - Dynamic coupon promo code engine (`TASTE20` for 20% off, `WELCOME10` for 10% off).
   - Accurate tax, shipping, and total calculations.
   - Cart persistence via `localStorage`.

5. **Multi-Step Checkout & Order Flow**:
   - Step 1: Contact & Shipping address form with one-click "Fill Demo Info" shortcut for rapid testing.
   - Step 2: Shipping speed selection (Standard Free Delivery vs Priority Express $15).
   - Step 3: Secure card payment input (with formatted card numbers and CVC) and Apple Pay / Google Pay simulated one-click checkout.
   - Live order processing spinner state.
   - Step 4: Celebration screen with confetti explosion, generated order number (`#AET-XXXXXX`), estimated delivery timeline tracker, and itemized receipt breakdown.

6. **Responsive UX / Mobile Support**:
   - Mobile slide-over navigation drawer.
   - Touch-optimized tap targets.
   - Sticky blur-glass header with quick bag and wishlist counters.
   - Accessible keyboard controls (Escape closes open drawers/modals).
